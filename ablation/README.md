# Ablation 对比记录

这个目录记录优化是否真的有必要、带来了什么效果、是否值得保留。

每个重要优化都应有一份 ablation 记录，至少包含：

- baseline 命令和报告路径
- 优化版命令和报告路径
- 唯一变化的变量
- 对比指标：成功率、总步数、平均步数、总耗时、平均耗时、失败类型、误触/恢复次数
- 结论：保留、回滚、继续观察或缩小适用范围

文件名必须使用 `MMDD-HHMM` 时间前缀，方便自然排序和按时间线 review：

```text
MM-DD/MMDD-HHMM-topic.md
```

例如：

```text
04-26/0426-1640-grounding-check.md
```
